# iforodrigez

A dark VS Code theme where the UI chrome gets out of the way: no gradients, no tinted panels, one accent color.

Twelve variants on two axes. **Ink** is how loud the syntax colors are — `low`, `medium`, `high`. **Background** is how dark the surfaces sit — `0` is pitch black, `3` is the gray VS Code ships with.

`Ctrl+K Ctrl+T` and pick a variant.

Full documentation, screenshots and the matching Zed themes: <https://github.com/ifrankerem/iforodrigez-themes>
